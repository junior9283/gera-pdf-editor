# Política de segurança

O Gera PDF Editor abre arquivos de terceiros, assina documentos e guarda certificados, então falhas
de segurança são tratadas com prioridade.

## Versões atendidas

Correções de segurança saem sempre para a versão mais recente.

## Como relatar

**Não abra issue pública.** Use o
[relato privado de vulnerabilidade do GitHub](https://github.com/junior9283/gera-pdf-editor/security/advisories/new)
e informe:
- versão afetada;
- descrição e impacto;
- passos ou arquivo para reproduzir (sem dados pessoais).

Você receberá retorno o quanto antes. Depois da correção publicada, o relato pode ser divulgado com
os devidos créditos.

Falhas no MuPDF devem ser relatadas também à [Artifex](https://bugs.ghostscript.com/).
