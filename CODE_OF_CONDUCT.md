# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso e acolhedor, aceite críticas construtivas, foque no que é melhor para a
comunidade e não tolere assédio, ofensas ou ataques pessoais, em issues, pull requests ou qualquer
outro espaço do projeto.

Comportamentos inaceitáveis podem ser relatados aos mantenedores pelo
[relato privado do GitHub](https://github.com/junior9283/gera-pdf-editor/security/advisories/new)
ou por issue marcada como "conduta". Todos os relatos são analisados com sigilo.
